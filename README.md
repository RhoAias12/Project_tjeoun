# 🌐 **JobaBug**  
### 통합 채용 공고 검색 및 지원 관리 플랫폼  
> **2025 더조은 아카데미 최종 프로젝트**

---

## 🧩 **서비스 소개**  
JobaBug은 **다양한 채용 사이트의 공고를 주기적으로 통합 수집**하고,  
**Elasticsearch 기반의 고성능 복합 검색 기능**과 **시각화 대시보드**를 제공하는 플랫폼입니다.  

- 사용자는 **포지션, 기술 스택, 지역** 등 맞춤형 필터링을 통해 **최적의 채용 정보 탐색** 가능  
- **즐겨찾기 및 지원 이력 관리 기능** 제공  
- **OpenAI API 기반의 지능형 챗봇** 탑재 → 실시간 질의응답 지원  
- **관리자 페이지**를 통해 사용자 및 공고를 체계적으로 관리  

---

## 🛠️ **사용 프로그램**
- Java 17
- Spring Boot 3.3.12
- MariaDB
- Elasticsearch 8.17.4
- Kibana 8.17.4
- Docker 28.1.1
- Nginx
