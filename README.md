# [JobaBug] 통합 채용 공고 검색과 지원 관리 플랫폼
2025 더조은 아카데미 최종 프로젝트<br/><br/><br/>
  
## 서비스 소개  
다양한 채용 사이트의 공고를 주기적으로 통합 수집하고, Elasticsearch 기반의 고성능 복합 검색 기능 및 시각화 대시보드를 제공하는 플랫폼입니다.<br/>사용자는 포지션, 기술 스택, 지역 등 맞춤형 필터링을 통해 최적의 채용 정보를 탐색하고, 즐겨찾기 및 지원 현황을 효율적으로 관리할 수 있습니다.<br/>OpenAI API를 활용한 지능형 챗봇이 탑재되어 있어, 사용자 질문에 대한 실시간 답변을 지원합니다.<br/>관리자 페이지에서는 사용자 및 공고 관리 기능을 통해 플랫폼 운영을 체계적으로 지원합니다.
<br/><br/><br/>
